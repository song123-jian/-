# 工作 1.7.4

程序显示名称、登录/主窗口、EXE、安装/卸载提示、快捷方式和开始菜单均已统一为“工作”。内部产品、账号与数据标识继续兼容。

## 使用位置

当前项目文件夹最外层提供 [工作.exe](../../工作.exe)、[工作快捷启动.lnk](../../工作快捷启动.lnk)、[工作-1.7.4-Setup.exe](../../工作-1.7.4-Setup.exe) 和 [工作图标.ico](../../工作图标.ico)。双击EXE或快捷方式直接运行；需要安装版时运行Setup。系统桌面另有安装包和图标副本。

安装版创建“工作”桌面快捷方式和“工作”开始菜单目录。若已有旧安装版，应先退出并卸载旧版；卸载保留data，安装版不会自动迁移便携版数据。“记住账号密码（仅本机当前Windows用户）”是本机保存的密码加密范围，应用账号可在其他电脑重新输入凭据登录。

## 有效验证

- 环境：Windows 11 x64；Python3.13.16、PyInstaller6.22.3生成的实际1.7.4 EXE和Setup。旧虚拟环境运行时路径已恢复，复用已有依赖。
- 4个相关Python文件Ruff、10个修改文件AST/UTF-8无BOM/替换字符/换行检查、相关PowerShell解析通过；人工增量差异审查完成。登录UI离屏5项通过、退出0；首次原生Qt测试异常退出不计入通过结果。
- 实际Setup在独立中文路径安装退出0，全部payload哈希匹配，3个快捷方式改名、目标和工作目录正确。实际安装EXE窗口显示“工作 · 程序账号登录”“登录工作”，runtime版本1.7.4；窗口观察不代表成功登录已验证。
- 隔离验收程序清理后卸载退出0，程序及3个快捷方式移除，data标记哈希未变。正常模式注册表入口未实际写入验收。
- 文件夹最外层和桌面副本逐一SHA256一致，启动快捷方式回读的目标和工作目录正确。详见 [安装验证记录](安装验证记录.json) 和 [交付文件核验](交付文件核验.json)。
