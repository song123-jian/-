# 工作 Android

原生 Kotlin / Jetpack Compose 客户端，Android 8.0 (API 26) 及以上。当前版本 1.23/code6，个人侧载使用 debug APK，无商店发布和正式发布签名流程。Android 安装要求有效签名，因此 debug 构建仍由 Gradle 自动使用本机 debug 证书签名。

当前交付 [工作手机版-1.23-debug.apk](../../工作手机版-1.23-debug.apk)，沿用本机debug证书覆盖升级，保留上一版1.22包及已有会话，不要为升级先卸载应用。

手机显示名称为“工作”，界面全部15级文字样式统一比Material基线小1sp，保留系统字号缩放；导出合同与报价单的原件字号、版式和图章不变。客户目录提供“新增客户”，按电脑端同样规则录入首次报价后自动建档并回到客户目录。

单据按用户指定Word原件生成，新增可编辑Word导出，PDF使用原页面资源与原字体。合同每页2项并保留原章；报价每页1项，原件无章。内容超长时明确拒绝，不压缩字号；同输入原件Word/PDF保持原字节，两端编辑/多页样本部件及同渲染器像素对照见测试交接。共享模板资源位于`app/src/main/assets/business_templates`，仅本机交付，未公开上传。

## 数据连接

手机和电脑必须使用同一个 Supabase 项目及同一个应用账号。报价、客户状态和历史共用个人云数据，不是文件复制同步，也不会自动上传电脑原本的本地 SQLite 数据。单据草稿、默认供方资料和本机恢复库按账号隔离保存在各自设备；它们不属于云同步范围。MES使用其独立账号和网络。

本地 `app/src/main/assets/account_config.json` 是从现有电脑程序提取的公开客户端配置，仅含项目地址、Publishable key 和用户名域，已被 Git 忽略。它不含密码、用户令牌或高权限凭据。源码未带该文件时，应用仍可在登录页手工配置；格式参考同目录 example 文件。禁止使用 Secret key、service_role 或数据库密码。

优先使用 `pmu-mobile` 网关；仅在会话发现明确返回网关未部署时，使用桌面相同的、受用户 JWT/RLS 约束的 REST/RPC。读取使用个人`pmu_*`接口；移动专用保存/历史接口确实缺失时，兼容既有电脑端原子保存RPC和RLS历史读取。补齐及图片报价检查个人`pmu_settings`，不访问共享业务表。不自动部署、迁移或放宽云端权限。

前台每 15 秒检查同步版本，后台暂停轮询，回到前台重新检查。首次同步成功前不开放新增。密码只用于当次认证；会话和待核对请求由 Android Keystore AES-GCM 加密，云备份和设备迁移排除这些偏好。保存前同步落盘请求；不确定结果及重试失败保留同一编号，不自动创建重复保存。加密记录不可读时保留原文并停止覆盖。

## 构建

需要 JDK 17、Android SDK Platform 36 / Build Tools 36.0.0，项目自带 Gradle 9.1 Wrapper。设置 `JAVA_HOME` 和 `ANDROID_HOME` 后，在本目录执行：

```powershell
.\gradlew.bat --no-daemon :app:assembleDebug :app:testDebugUnitTest
```

产物：`app/build/outputs/apk/debug/app-debug.apk`。覆盖升级必须保留同一个本机 debug 签名证书；不同证书不能直接覆盖安装。不要为升级而卸载含待核对保存请求的应用。

本机 Windows 中文路径会影响 Java 17 的测试工作进程，可为同一目录设置英文盘符（先确认盘符空闲）。当前Z盘已由本工作区共用，不要重复建立或自动撤销。当前机器的 Temurin C1 编译线程曾崩溃，本次仅在命令行关闭分层编译，没有修改全局 Java 设置：

```powershell
Set-Location Z:\
$env:JAVA_OPTS = '-XX:-TieredCompilation -Dfile.encoding=UTF-8'
.\gradlew.bat --no-daemon --console=plain '-Dorg.gradle.jvmargs=-Xmx2048m -Dfile.encoding=UTF-8 -XX:-TieredCompilation' '-Pkotlin.compiler.execution.strategy=in-process' :app:assembleDebug :app:testDebugUnitTest
Set-Location 'E:\工作'
```
