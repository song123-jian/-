# 单据原件模板

1.7.9与手机1.2默认使用本次提供的合同和报价单原件。`source-layout.json`定义可编辑文字的定位，`source-{kind}.docx/pdf`保留原始Word包和本机WPS导出的参考页面；字体、表格、页眉页脚、Logo、签章图片与定位保持原件规则。合同每页2项，报价单每页1项；内容超长明确提示缩短或拆分，不自动缩小字号。合同保留原章，报价单原件无章，不额外盖章。

Word导出仅替换声明的文字节点，原样数据直接返回原DOCX字节；多页按原节和表格模式续页。PDF保留参考页面操作与字体/图片资源，仅替换业务字段；同数据两端样本在同一PDFium渲染器2倍比例逐像素一致。修改内容后的Word布局仍由打开它的Word/WPS排版引擎处理，不声称任意软件或任意字段长度都能绝对相同。

本次原件和字体只用于本机生成与本机安装包，未公开上传。不要将包含原始客户、联系方式或银行资料的模板提交到公开仓库。`source/build_source_templates.py`是本机资源编译辅助工具，需要原件与其参考PDF，不属于运行时转换依赖。重编译须同时提供`--references`和`--date-references`，后者含WPS按原数字分段导出的`quotation-date-{1-1,1-2,2-1}.pdf`；缺少短日期资源时生成明确拒绝，不用近似间距替代。
