## 当前结论

2026-10-22 MES 范围变更：用户明确要求恢复历史 HTTP 功能，并将 HTTPS 443 证书验收排除于本轮。1.7.8 仅允许原 MES 主机/端口走 HTTP，其他 HTTP 地址仍拒绝。冻结 EXE 本地合成登录通过，真实 MES 登录未运行；HTTP 凭据明文传输风险仍存在。历史 443 自签名证书链失败记录保留，但不作为本轮阻塞。

整体优化目标仍未全部完成，未完成项主要是 Supabase 隔离测试项目/写入与清理范围、服务端变更、真实注册和密钥轮换。当前 main 有业务数据，不得视为隔离测试库。MES 443 证书链失败保留为历史事实，但 HTTPS 443 验收已由用户明确排除，不是本轮阻塞，也不影响 1.7.8 指定 HTTP 功能恢复。其余外部验收边界见[隔离验收执行清单](阶段二隔离验收执行清单-20261021.md)。

2026-10-21 的阶段记录：阶段一已完成；阶段二当时实施 MES 明文阻止和遗留入口隔离，后续 MES 范围由用户要求更新为 1.7.8 指定 HTTP 主机/端口例外；云端迁移仍未完成。阶段三本地代码及隔离写入退出已验证，真实外部注册/网络场景尚未完成；阶段四已建立本地性能基线，本轮未实施额外性能或架构改写。整体优化方案尚未全部验收完成。

当前桌面端交付为 [工作-1.7.8.exe](../工作-1.7.8.exe) 与 [工作-1.7.8-r9-Setup.exe](../工作-1.7.8-r9-Setup.exe)，哈希及安装状态见[交接记录](HANDOFF.md)。1.7.6-r5 是 2026-10-21 的历史候选，EXE 已移入[手动删除目录](../手动删除/work/release-phase2-local-security-1.7.6-r5/工作.exe)，构建与验收证据保留。D 盘安装的后续状态见交接记录，不沿用本矩阵较早的“保留原样”结论。阶段二到四的本地验收使用合成数据和独立 SQLite，不写真实账号或报价。

## 本地性能基线

环境为 Windows 11 x64、Python 3.13.16、原生 Windows Qt 平台。入口是 `source/desktop_main.py --data-dir <独立目录> --smoke-test <报告目录>`。记录源码和测量脚本 SHA256，网络由测量驱动拦截，实际请求数为0。使用既有隔离入口跳过账号登录，文件选择器返回合成CSV路径；其余预览、提交和查询使用实际界面与真实 SQLite。

| 操作 | 进程首开中位/p95（ms） | 重复打开中位/p95（ms） |
| --- | --- | --- |
| 启动到1000条数据的可用窗口 | 1337.650 / 1349.350 | 1354.160 / 1372.615 |
| 首次查询 | 43.165 / 45.677 | 41.377 / 44.032 |
| 连续查询 | 28.601 / 33.318 | 28.299 / 32.458 |
| 首次刷新 | 279.610 / 288.010 | 284.618 / 293.288 |
| 250条导入预览+提交后刷新 | 823.350 / 838.685 | 813.348 / 854.221 |
| 明确退出到进程结束 | 132.461 / 142.290 | 131.192 / 156.176 |

操作计时处理自然 Qt 事件，不强制重绘整窗。7个样本的最近秩p95等于该组最大观测值；连续查询每组21次，来自7个进程。系统/文件缓存未清空，不能称磁盘冷启动。启动包含源码及验收模块导入，不代表冻结EXE解包、真实账号登录或云端吞吐；导入不含人工选择/输入时间。旧 `runs/` 含强制重绘且采样期间修改过驱动，已停止并弃用，不纳入上述结论。
